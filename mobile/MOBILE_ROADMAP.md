# Mobile Roadmap

## 方針

React Native版は、Web版をそのまま移植するだけではなく、スマホで毎日使う前提に寄せます。最初の判断として、ブラウザ版の延長ではなく「スマホアプリとして自然に見える在庫 / 取引管理」にします。

## Phase 1: 動くMVP

- Supabase Auth でログイン / 新規登録
- 在庫の追加 / 編集 / 削除
- 取引の追加 / 編集 / 削除
- 画像を private bucket に保存
- ログインユーザー本人のデータだけ表示

## Phase 2: 既存Web版と同等にする

- 在庫の並び替え
- 取引ステータス変更時の在庫数連動
- 梱包済 / 発送済 / 受取済のクイック操作
- 取引相手、メモ、画像ありなしの検索 / 絞り込み
- 発送予定日 / 受取予定日の入力を日付ピッカーに変更

## Phase 3: 販売できる品質にする

- アプリ名、アイコン、ブランドカラーの確定
- 初回オンボーディング
- 空状態、エラー状態、通信中表示
- 利用規約 / プライバシーポリシー
- 問い合わせ導線
- バックアップ / エクスポート
- 本番Supabase projectへの切り替え

## Phase 4: ストア公開

- Apple Developer Program 登録
- Google Play Console 登録
- EAS Build 設定
- TestFlight / 内部テスト
- ストア文言、スクリーンショット、年齢区分、プライバシー回答
- 課金を入れる場合は、RevenueCatなどの導入を検討
